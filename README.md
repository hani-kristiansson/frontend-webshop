# Frontend Webshop "By Hani" – Project Overview 🛒

This project focuses on creating a basic web shop where users can browse products, add them to a shopping cart, adjust quantities, and remove items. 
The website is responsive, adapting to different screen sizes, and allows users to fill in a delivery address. 
The cart data is saved in the browser using LocalStorage, so it persists even after a page reload.

You can check out the live version of the project here: [Frontend Webshop Demo](https://hani-kristiansson.github.io/frontend-webshop/)

## Features: ✅

- Add products to the cart
- Change product quantities
- Remove individual products
- Remove all products from the cart
- Show the total cost
- Local storage support 

## Improvements to consider: 🚀

- **User Interface**: The visual layout could use some extra love
- **Additional Features**: Could add things like discounts, product details, p-marker
- **API Integration**: Use an API to handle address input and other related data such as Postnord API, Google maps API

## Tools & Resources Used: 🛠️

- **JavaScript**
- **HTML/CSS**
- **LocalStorage**: To save cart data between page reloads.
- **API**: [FakeStoreAPI](https://fakestoreapi.com/) for fetching product data.
- **Images**: Generated using ChatGPT for brand logo, image on main page.
